# 📝 To-Do List

A simple and beginner-friendly To-Do List web application built using **HTML, CSS, and JavaScript**.

This project allows users to add tasks, mark tasks as completed, and delete tasks.

## 🚀 Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- ❌ Delete tasks
- 🎨 Simple and attractive user interface
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
